## Workflow (git flow, enforced)

This workspace and `apple-neural-engine-training` use **git flow** ([git-flow-next](https://github.com/gittower/git-flow-next), classic preset): `main` holds releases, `develop` is the integration branch, and work happens on `feature/`, `bugfix/`, `release/`, `hotfix/` or `support/` branches. The other submodules are read-only references and track their upstream `main`.

- **Setup after cloning:** `git clone --recurse-submodules https://github.com/o2alexanderfedin/apple-neural-engine && cd apple-neural-engine && scripts/setup-git-flow.sh`. The script initializes git flow and installs the guard hooks from [.githooks/](.githooks/) in both repos. See [scripts/setup-git-flow.sh](scripts/setup-git-flow.sh).
- **Locally:** [pre-commit](.githooks/pre-commit) blocks commits on `main`/`develop`. [pre-push](.githooks/pre-push) blocks branch names other than `main`, `develop` and git-flow prefixes. Emergency bypass: `GITFLOW_BYPASS=1`.
- **On GitHub:** a ruleset on `main` and `develop` in both repos ([workspace](https://github.com/o2alexanderfedin/apple-neural-engine/rules), [training fork](https://github.com/o2alexanderfedin/apple-neural-engine-training/rules)) blocks force-pushes and deletion. Solo project, so **no pull requests**: changes land with a local `git flow … finish`, then a push. `develop` is the default branch.
- **Typical cycle:** `git flow feature start x` → commit (optionally `git flow feature publish`) → `git flow feature finish x` → `git push origin develop`. Releases: `git flow release start 1.0` → `git flow release finish 1.0` → `git push origin main develop --tags`.
